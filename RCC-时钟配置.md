# RCC的主要作用

* 设置`SYSCLK 系统时钟``AHB 分频因子``APB2 分频因子`

* 整个芯片所有的外设内核能够跑起来的心跳配置

*  时钟源 → SYSCLK 生成路径

```textile
┌──────────────────────────────────────────────────────────────┐
│                        时钟源部分                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   HSI ─────────────────────────────┐                         │
│   内部高速时钟                      │                         │
│   典型 8MHz / 16MHz                │                         │
│                                    │                         │
│                                    ▼                         │
│                                 SYSCLK                       │
│                                    ▲                         │
│                                    │                         │
│   HSE ─────────────────────────────┘                         │
│   外部高速时钟                                                │
│   典型 4~26MHz                                              │
│                                    ▲                         │
│                                    │                         │
│                                    │                         │
│   PLL ─────────────────────────────┘                         │
│   锁相环倍频                                                  │
│   输入：HSI / HSE                                            │
│   输出：PLLCLK                                               │
│                                                              │
│   LSI ──────────────┐                                        │
│   内部低速时钟       │                                        │
│   约 32~40kHz       │                                        │
│                     ▼                                        │
│                  RTC / IWDG                                  │
│                     ▲                                        │
│   LSE ──────────────┘                                        │
│   外部低速时钟                                                │
│   典型 32.768kHz                                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

* SYSCLK → HCLK → PCLK1 / PCLK2 分配路径

```
┌──────────────────────────────────────────────────────────────┐
│                      系统时钟分配部分                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                         SYSCLK                               │
│                            │                                 │
│                            ▼                                 │
│                     AHB Prescaler                            │
│                            │                                 │
│                            ▼                                 │
│   HCLK = SYSCLK / AHB_Prescaler                              │
│                            │                                 │
│        ┌───────────────────┴───────────────────┐             │
│        ▼                                       ▼             │
│   APB1 Prescaler                         APB2 Prescaler      │
│        │                                       │             │
│        ▼                                       ▼             │
│   PCLK1 = HCLK / APB1_Prescaler         PCLK2 = HCLK / APB2_Prescaler
│        │                                       │             │
│        ▼                                       ▼             │
│   低速外设总线                            高速外设总线        │
│   USART2/3、I2C、SPI2/3、CAN            USART1、SPI1、ADC   │
│   TIM2~TIM7 等通用定时器                 TIM1、TIM8 等高级定时器
│                                                              │
│   定时器时钟规则：                                            │
│   若 APB 预分频系数 = 1：TIM_CLK = PCLKx                     │
│   若 APB 预分频系数 > 1：TIM_CLK = PCLKx × 2                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
